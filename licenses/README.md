# Third-party components

The binaries include SQLite 3.54.1 and nlohmann/json 3.12.0. SQLite's authors dedicate its deliverable code to the public domain. See [SQLite's copyright statement](https://sqlite.org/copyright.html). The MIT notice for nlohmann/json is included in this directory.

The x64dbg integration builds against the official 2026.05.27 plugin SDK. Get the compatible debugger from the [x64dbg release](https://github.com/x64dbg/x64dbg/releases/tag/2026.05.27).
